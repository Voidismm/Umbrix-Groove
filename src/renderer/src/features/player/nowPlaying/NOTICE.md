# Third-party visualization engine

WebGL visualization scenes, presets, and audio-feature helpers under this folder
are adapted from **[Manaiakalani/now-playing](https://github.com/Manaiakalani/now-playing)**
(MIT License). See `LICENSE-now-playing.txt`.

Tribute recreation of classic Windows Media Player visualization *names* and looks.
No Microsoft binaries or reverse-engineered WMP plugins are included.

## Butterchurn (Milkdrop)

The Milkdrop family uses **[butterchurn](https://github.com/jberg/butterchurn)** and
**[butterchurn-presets](https://github.com/jberg/butterchurn-presets)** (MIT License).
Presets are converted MilkDrop patterns; colors are authored inside each preset.
